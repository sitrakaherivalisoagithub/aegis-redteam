# Aegis AI Red Team - Development Roadmap

- Python project initialization and dependency management.
- Configuration system and Pydantic schemas.
- FastAPI backend foundation.
- SQLite persistence layer.
- Basic tests.

## Phase 2 — Repository Discovery
- Deep Agents integration.
- Repository connectors (Local, GitHub).
- Architecture and dependency inventory.

## Phase 3 — Threat Intelligence
- Code Auditor, Threat Modeler, OWASP Mapper, Test Planner.
- Versioned security catalogs.

## Phase 4 — Red Team Execution
- Target configuration and adapters.
- Promptfoo, PyRIT, and Native execution engines.

## Phase 5 — Evaluation and Risk
- Deterministic and LLM-as-a-judge evaluations.
- Risk scoring and finding lifecycle.

## Phase 6 — Reporting and Dashboard
- Streamlit UI implementation.
- Reporting engine (Markdown, JSON).
